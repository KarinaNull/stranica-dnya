# Страница дня

Веб-приложение, которое раз в день показывает одну новую страницу по выбранной теме.

Темы: Википедия, Путешествия (Викигид), Космос (фото дня NASA), Кандзи и Английские слова (Викисловарь).
Статьи берутся из открытых API и сохраняются в базу данных PostgreSQL.

## Что умеет приложение

- Вверху выбирается тема, для каждой темы показывается своя статья.
- Таймер показывает, сколько осталось до новой страницы. Когда он доходит до нуля, по всем темам загружаются новые статьи.
- Кнопка «Прочитано» добавляет статью в историю.
- В блоке «История прочитанного» видны прочитанные статьи.
- Регистрации нет. При первом заходе пользователю выдается случайный идентификатор, он хранится в куке, а в базе по нему создается читатель.

## Структура проекта

| Файл | Что делает |
| --- | --- |
| `index.php` | страница и основная логика (таймер, кнопка «Прочитано», история) |
| `api.php` | запросы к API и приведение ответов к одному виду |
| `connect.php` | настройки подключения к базе данных |
| `db.php` | подключение к базе данных и функции для работы с ней |
| `setup.php` | страница первого подключения, создает базу и таблицы |
| `style.css` | стили |
| `script.js` | обратный отсчет таймера |
| `db/2_tables.sql` | создание таблиц |
| `db/3_data.sql` | темы и тестовые данные |
| `db/4_queries.sql` | 5 запросов к базе данных |

Файл `config.php` с паролем от базы создается автоматически при первом запуске и в репозиторий не добавляется.

## Как запустить

Нужен установленный и запущенный PostgreSQL и интернет для загрузки статей.

**Вариант 1. Через PHP Desktop (exe)**

1. Распаковать архив `phpdesktop-chrome-130.1-php-8.3.zip` в любую папку.
2. Запустить `phpdesktop-chrome.exe`.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажать «Подробнее», а потом «Выполнить в любом случае». У программы нет цифровой подписи, поэтому появляется это окно.

Ставить PHP или веб-сервер отдельно не нужно, внутри уже есть PHP 8.3 и встроенный браузер.

**Первый запуск**

Откроется страница подключения к базе данных. Нужно ввести пароль от пользователя postgres (если порт или пользователь другие, поменять их там же) и нажать «Подключиться». База `stranica_dnya`, таблицы и тестовые данные создадутся автоматически из файлов `2_tables.sql` и `3_data.sql`.

## Какие API используются

| Тема | API |
| --- | --- |
| Википедия | ru.wikipedia.org, случайная статья |
| Путешествия | ru.wikivoyage.org, случайная статья Викигида |
| Космос | api.nasa.gov, фото дня NASA (APOD) |
| Кандзи | kanjiapi.dev |
| Английские слова | en.wiktionary.org, значения английских слов |

У NASA используется демо-ключ `DEMO_KEY`, у него есть ограничение на количество запросов в час. Если тема «Космос» не загрузилась, нужно подождать и нажать «Попробовать снова».
